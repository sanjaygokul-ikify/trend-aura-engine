# Contributing to AURA Engine

AURA Engine is an open-source project that welcomes contributions from the community. To contribute to AURA Engine, follow these steps:
1. Fork the repository using `git fork https://github.com/aura-engine/aura-engine.git`
2. Navigate to the forked repository using `cd aura-engine`
3. Create a new branch using `git branch feature/new-feature`
4. Make changes to the code and commit them using `git commit -m 'New feature'`
5. Push the changes to the remote repository using `git push origin feature/new-feature`
6. Create a pull request using `git pull-request feature/new-feature`
